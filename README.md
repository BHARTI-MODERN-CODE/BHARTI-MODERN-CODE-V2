BHARTI MODERN CODE (BMC) — Version 2.0: Official language system documents, grammar rules, phonetics, and writing standards.
# 🇮🇳 BHARTI Modern Language Framework

> **A logical, AI-friendly, and culturally inclusive universal language framework rooted in Indian heritage.**

---

## 📖 परिचय (About The Project)

**BHARTI** एक आधुनिक भाषा और संचार प्रणाली (Communication System) है, जिसे AI पार्सिंग, मानव स्पष्टता (Human Clarity) और सांस्कृतिक समावेशिता (Cultural Inclusivity) को ध्यान में रखकर डिज़ाइन किया गया है। इसका मुख्य उद्देश्य एक तार्किक और **Zero-Exception Grammatical Framework** तैयार करना है, जो बिना किसी अनावश्यक जटिलता के आसानी से समझ में आए।

---

## 🗂️ प्रोजेक्ट संरचना (Project Structure & Documentation)

यह प्रोजेक्ट विभिन्न व्याकरणिक प्रणालियों (Grammatical Systems) और मॉड्यूल्स में विभाजित है:

### 1. शब्द-निर्माण और रूप-विज्ञान (Word Formation & Morphology)
* **Noun System (`noun-system.md`):** वास्तविक/काल्पनिक और भौतिक/अमूर्त के आधार पर संज्ञा (Noun) की 4 मुख्य श्रेणियाँ।
* **Pronoun System (`pronoun-system.md`):** 3-पुरुष प्रणाली (`Mi`, `Tu`, `Ye`, `Vo`), सार्वभौमिक बहुवचन नियम (`'s`), और सम्मानसूचक (`ji`)।
* **Determiner System (`determiner-system.md`):** 6 कोर निर्धारक (Demonstrative, Possessive, Quantitative, Numeral, Indefinite, Distributive)।
* **Adjective System (`adjective-system.md`):** 7 कोर श्रेणियों और **Zero-Change Rule** पर आधारित विशेषण।
* **Adverb System (`adverb-system.md`):** क्रिया, विशेषण या पूरे कथन को मॉडिफ़ाई करने वाले 6 क्रिया-विशेषण प्रकार।

### 2. संख्या-प्रणाली (Numeral System)
* **Numeral System (`numeral-system.md`):** भारतीय स्थान-मूल्य (Place-Value) संरचना, स्पेस-सेपरेटेड टोकन्स, और `MahaSankh` तक के बड़े संख्यात्मक मात्रक।
