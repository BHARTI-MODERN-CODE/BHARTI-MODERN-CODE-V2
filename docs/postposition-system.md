## 1. Definition (परिभाषा)

Postposition वह grammatical marker है जो Noun या Noun Phrase के बाद आकर वाक्य में उसके संबंध या भूमिका को व्यक्त करता है।

---

## 2. Core Categories (मुख्य श्रेणियाँ)

### 01. NE — कर्ता / Agent Marker
* **कार्य:** कर्ता या कार्य करने वाले को दर्शाता है।
* **उदाहरण:** `Ram ne kitab padhi.`  
* **अर्थ:** राम ने किताब पढ़ी।

### 02. KO — Object / Recipient Marker
* **कार्य:** कर्म या प्राप्तकर्ता को दर्शाता है।
* **उदाहरण:** `Ram ne Sita ko dekha.`  
* **अर्थ:** राम ने सीता को देखा।

### 03. LIYE — Purpose / Beneficiary Marker
* **कार्य:** उद्देश्य या लाभार्थी को दर्शाता है।
* **उदाहरण:** `Ram Sita liye kitab laya.`  
* **अर्थ:** राम सीता के लिए किताब लाया।

### 04. SE — Instrumental / Source
* **कार्य:** कार्य करने के साधन या उपकरण तथा किसी वस्तु या क्रिया के स्रोत या उत्पत्ति को दर्शाता है।
* **साधन का उदाहरण:** `Ram qalam se likh ra ha.` (राम कलम से लिख रहा है।)
* **स्रोत का उदाहरण:** `Pahar se pani aata ha.` (पहाड़ से पानी आता है।)

### 05. TE — Separation / Ablative
* **कार्य:** किसी वस्तु से अलग होने या उससे दूर होने का संबंध दर्शाता है।
* **उदाहरण:** `Ped te patta gira.`  
* **अर्थ:** पेड़ से पत्ता गिरा।

### 06. ME — Location / Inside
* **कार्य:** किसी स्थान या वस्तु के भीतर होने का संबंध दर्शाता है।
* **उदाहरण:** `Kitab dibbe me ha.`  
* **अर्थ:** किताब डिब्बे में है।

### 07. PE — Location / Surface
* **कार्य:** किसी सतह या स्थान पर होने का संबंध दर्शाता है।
* **उदाहरण:** `Kitab mez pe ha.`  
* **अर्थ:** किताब मेज़ पर है।

### 08. KA — Possession / Relationship
* **कार्य:** स्वामित्व या संबंध दर्शाता है।
* **उदाहरण:** `Yeh Ram ka ghar ha.`  
* **अर्थ:** यह राम का घर है।

### 09. TARF — Direction
* **कार्य:** किसी दिशा या ओर जाने का संबंध दर्शाता है।
* **उदाहरण:** `Ram ghar tarf gaya.`  
* **अर्थ:** राम घर की ओर गया।

### 10. TAK — Limit / Endpoint
* **कार्य:** किसी समय या स्थान की सीमा अथवा अंतिम बिंदु दर्शाता है।
* **उदाहरण:** `Meeting pach baje tak hai.`  
* **अर्थ:** मीटिंग पाँच बजे तक है।

## 3. Important Distinctions (महत्वपूर्ण अंतर)

* `SE` एक ही Core Category है, जिसके दो उपयोग हैं:
  * **Instrumental / Means** — साधन
  * **Source / Origin** — स्रोत
* `TE` का उपयोग **Separation / Ablative** — अलगाव के लिए है।
* `SE` और `TE` के कार्य अलग-अलग रखे गए हैं।
