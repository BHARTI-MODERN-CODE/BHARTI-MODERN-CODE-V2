## 1. Definition & Core Categories (परिभाषा और मुख्य श्रेणियाँ)

* **परिभाषा:** Adjective वह वर्णनात्मक घटक है जो सीधे Noun की विशेषता बताता है।

* **7 Core Categories:**
  1. **Quality / State** (गुण / अवस्था) — `achha`, `bura`, `naya`, `purana`
  2. **Size / Dimension** (आकार / माप) — `bada`, `chhota`, `lamba`, `chauda`
  3. **Color** (रंग) — `lala`, `kala`, `safed`, `hara`
  4. **Physical Property** (भौतिक गुण) — `bhari`, `halka`, `garam`, `thanda`
  5. **Shape** (रूप / आकृति) — `gol`, `seedha`, `tedha`
  6. **Speed / Intensity** (गति / तीव्रता) — `tez`, `dheema`, `tivra`, `mand`
  7. **Mental / Behavioral** (मानसिक गुण) — `buddhiman`, `imaandar`, `dayalu`

## 2. Usage, Structure & Multiple Adjectives (प्रयोग और संरचना)

* **Basic Structure:** `Determiner + Adjective(s) + Noun`
* **Multiple Adjectives:** एक Noun Phrase में एक से अधिक Adjectives आ सकते हैं। कोई कठोर क्रम (Order) अनिवार्य नहीं है, बशर्ते संयुक्त अर्थ तार्किक हो।
* **उदाहरण:** `"Ye bada sundar lala ghar"`

---

## 3. Critical Rules & Boundaries (महत्वपूर्ण नियम और सीमाएँ)

* **Zero-Change Rule:** Adjective लिंग, वचन या Case के अनुसार कभी अपना रूप नहीं बदलेगा (अपरिवर्तनीय)।
* **Functional Category Rule:** शब्द की Grammatical Category केवल उसके अर्थ या स्थान से नहीं, बल्कि वाक्य में उसके कार्य और दूसरे शब्दों के साथ उसके संबंध से तय होगी:
  * Noun का वर्णन करे $\rightarrow$ **Adjective** ("Fast car")
  * Verb को Modify करे $\rightarrow$ **Adverb** ("Ram runs fast")
  * Adjective को Modify करे $\rightarrow$ **Adverb** ("Very big house"; यहाँ "very" Adverb है और "big" Adjective है।)
* **Determiner vs Adjective:** Determiner संदर्भ/मात्रा तय करता है, जबकि Adjective गुण बताता है (`"Ye"` = Determiner, `"bada"` = Adjective)।
