## 1. VERB की परिभाषा (Definition)

BMC में Verb वह मूल वैचारिक शब्द या अवधारणा है जो किसी Action (कार्य), Event (घटना), State (अवस्था) या Process (प्रक्रिया) को व्यक्त करती है।

* **उदाहरण:** `"padh"` (पढ़ना), `"ja"` (जाना), `"likh"` (लिखना)।

---

## 2. VERB ROOT और उसकी अपरिवर्तनीयता (Root Invariance)

* BMC में Verb का मूल रूप **Verb Root** कहलाएगा।
* **सर्वोच्च नियम (Master Rule):** Verb Root हमेशा स्थिर और अपरिवर्तनीय (Invariable) रहेगा। यह कभी भी conjugate नहीं होगा।

### Root का रूप निम्नलिखित किसी भी कारण से नहीं बदलेगा:
1. **Person (पुरुष)** के कारण (जैसे: `Mi`, `Tu`, `Vo` के साथ Root समान रहेगा)।
2. **Number (वचन)** के कारण (Singular या Plural होने पर Root नहीं बदलेगा)।
3. **Gender (लिंग)** के कारण (Male, Female या Other होने पर Root समान रहेगा)।
4. **Tense (काल)** के कारण।
5. **Aspect (पक्ष)** के कारण।
6. **Negation (नकारात्मकता)** के कारण।
7. **Question (प्रश्न)** के कारण।

---

## 3. UNIVERSAL VERB PRINCIPLE (शून्य अनियमितता)

* BMC में सभी Verbs पर एक समान मूल grammatical framework लागू होगा।
* कोई भी **Irregular Verb (अनियमित क्रिया)** क्लास नहीं होगी।
* किसी भी Verb में Person, Number या Gender के आधार पर कोई प्रत्यय (Suffix) या बदलाव नहीं जोड़ा जाएगा।

---

## 4. अन्य प्रणालियों से अलगाव (System Boundaries)

* Verb System केवल Verb Root और उसके स्थिर रहने के नियमों को तय करता है।
* Tense और Aspect के नियम **Auxiliary System** के अंतर्गत स्वतंत्र रूप से संचालित होंगे।
* Negation (`"na"`) और Question (`"ki"`) अपने स्वतंत्र ऑपरेटर सिस्टम के तहत काम करेंगे। Verb Root इनके आने से भी नहीं बदलेगा।

---

## 5. VERB की वाक्यगत भूमिका और वैकल्पिक OBJECT

* **Verb की वाक्यगत भूमिका:** BMC में Verb वाक्य में Action, Event, State या Process को व्यक्त करता है।
* **मूल Word Order:** BMC का सामान्य वाक्य क्रम **SOV (Subject + Object + Verb)** होगा।
* **Object की वैकल्पिकता:** Object प्रत्येक वाक्य में अनिवार्य नहीं होगा। वाक्य में Object हो भी सकता है और नहीं भी।
* **Verb की स्थिति:** 
  * Object मौजूद होने पर सामान्य क्रम: `Subject + Object + Verb`
  * Object मौजूद न होने पर क्रम: `Subject + Verb`

### उदाहरण:
* `"Mi kitab padh ..."` — Subject + Object + Verb
* `"Mi ja ..."` — Subject + Verb (बिना Object के)

> **मूल नियम:** Verb वाक्य में Action, Event, State या Process को व्यक्त करता है, लेकिन Object की उपस्थिति अनिवार्य नहीं है।
